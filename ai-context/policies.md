# JeahLuy E-commerce Policies

## Shipping Policy
- **Free Shipping**: Orders over $50
- **Standard Shipping**: 3-5 business days ($5.99)
- **Express Shipping**: 1-2 business days ($12.99)
- **Regions**: We ship to Cambodia, USA, Japan, Singapore, and Thailand

## Return & Refund Policy
- **Return Period**: 30 days from delivery date
- **Condition**: Items must be unused, in original packaging
- **Refund Method**: Original payment method
- **Process**: 
  1. Go to Order History
  2. Select order to return
  3. Choose return reason
  4. Print return label
  5. Drop off at nearest carrier

## Payment Methods
1. **Cash on Delivery** (Available in Cambodia only)
2. **Credit/Debit Cards** (Visa, Mastercard, UnionPay)
3. **KHQR** (Cambodian QR code payment)
4. **PayPal** (International payments)

## Order Status Meanings
- **Pending**: Payment not yet confirmed
- **Processing**: Order being prepared
- **Shipped**: Order dispatched with tracking
- **Delivered**: Order received by customer
- **Cancelled**: Order cancelled by user or system

## User Account Management
- **Registration**: Requires email verification
- **Password Reset**: Available via Forgot Password page
- **Profile Update**: Can update address, phone, preferences
- **Order History**: All past orders accessible in profile

## Merchant Program
- **Requirements**: Valid ID, bank account, business license
- **Commission**: 10% per sale
- **Payout**: Bi-weekly to registered bank account
- **Support**: Dedicated merchant support team

## Security & Privacy
- **Data Protection**: Encrypted payment processing
- **Privacy**: We don't sell personal data
- **Cookies**: Used for shopping cart and preferences only
